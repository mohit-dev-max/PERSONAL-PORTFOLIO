## 🎨 Visual Identity & Design System

- **Color Discipline**: Strict 70% Black (`#050505`, `#0B0B0B`) / 20% White (`#F5F5F5`, `#B8B8B8`) / 10% Red Accents (`#E10600`, `#FF2A23`).
- **Interactive 3D WebGL Core**: Real-time rendering via Three.js with multifaceted obsidian geometry, ruby-red wireframe cage, pulsating inner core, and mouse parallax.
- **Interactive Ideas Node Canvas**: Dynamic connected problem-space nodes with traveling red data pulse animations.
- **Architectural Photo Frame**: Drag-and-drop / upload portrait preview with browser `localStorage` persistence.
- **Micro-Interactions**: Custom desktop cursor system, audio synthesizer via native Web Audio API, and live IST footer clock.

## 📂 Project Architecture

```
PERSONAL-PORTFOLIO/
├── index.html              # Semantic HTML5 architecture & all sections
├── README.md               # Repository documentation
├── .gitignore              # Ignored files
├── css/
│   └── style.css           # Tokens, typography scales, glassmorphism, responsive grid
├── js/
│   ├── main.js             # Cursor, photo upload, modals, dynamic GitHub API
│   ├── three-scene.js      # Three.js 3D WebGL hero digital sculpture
│   ├── ideas-canvas.js     # Connected node canvas for "Ideas worth building"
│   └── audio.js            # Synthesized interface audio system
└── vendor/
    └── three.min.js        # Local Three.js library for offline readiness
```

## 💻 Local Development

Clone the repository and open `index.html` in any modern web browser:

```bash
git clone https://github.com/mohit-dev-max/PERSONAL-PORTFOLIO.git
cd PERSONAL-PORTFOLIO
```

Or run with Python's local server:
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000`.
